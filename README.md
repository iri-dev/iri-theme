## Hey, I'm Iri

<p>
  <strong>pronounced <em>eye-ree</em></strong>
</p>

**iri theme** is my own VS Code theme. I designed it for myself, I code in it every day, and now I've made it public so you can use it too.

I wanted VS Code to feel like *mine*: deep violet everywhere, soft pink wherever you interact, and pastel code colours that are easy to read for hours. Purple is my favourite colour and I genuinely think it makes almost anything look better, so I went all in.

And I didn't stop at the editor. Menus, tabs, buttons, badges, the scrollbar, the cursor, even the terminal: I tuned every corner, one version after another, until the whole window felt like home.

## Little Extras

Alongside the colours, iri theme comes with a few finishing touches that make it feel complete:

- **A thin white line cursor** in both the editor and the terminal, crisp against the dark violet.
- **Pill-shaped tabs** in VS Code's Modern UI (where your version has it), so the active tab really stands out.
- **A slimmer horizontal scrollbar** that stays out of your way.

Prefer something different? Your own settings always take priority, so you can change any of these whenever you like.

## Try It

1. In VS Code, open the Extensions view (`Ctrl+Shift+X`), search for **iri theme** and click **Install**. You can also install it from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=iri-dev.iri-theme).
2. Press `Ctrl+K` `Ctrl+T` (`Cmd+K` `Cmd+T` on macOS) and pick **iri theme**.

Prefer a file? Download **`iri-theme-1.6.4.vsix`** from the [latest release](../../releases/latest), then in the Extensions view open the `…` menu and choose **Install from VSIX…**.

<details>
<summary><b>Good to know</b></summary>

**Setting the theme by hand?** In `settings.json` use `"workbench.colorTheme": "iri-theme"`.

**Odd highlight backgrounds while typing in Windows PowerShell?** That comes from an old version of PSReadLine. Update it, then reopen VS Code:

```powershell
Install-Module PSReadLine -Scope CurrentUser -Force
```

</details>
