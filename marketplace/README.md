## Hey, I'm Iri

**pronounced *eye-ree***

**iri theme** is my own VS Code theme. I designed it for myself, I code in it every day, and now I've made it public so you can use it too.

I wanted VS Code to feel like *mine*: deep violet everywhere, soft pink wherever you interact, and pastel code colours that are easy to read for hours. Purple is my favourite colour and I genuinely think it makes almost anything look better, so I went all in.

And I didn't stop at the editor. Menus, tabs, buttons, badges, the scrollbar, the cursor, even the terminal: I tuned every corner, one version after another, until the whole window felt like home.

## What Colour Is What?

![The iri theme palette](https://raw.githubusercontent.com/iri-dev/iri-theme/main/assets/brand/palette.png)

| What | Colour | Examples |
| --- | --- | --- |
| **Keywords** | Violet `#B18AFF` | `import` `const` `class` `if` `return` |
| **Strings** | Peach `#FFC39F` | `"hello"` `'iri'` |
| **Inside strings** | Pink `#FF59CB` | `${name}` `\n` |
| **Numbers, booleans and constants** | Gold `#FFE28A` | `5` `true` `null` `PETALS` |
| **Functions and methods** | Cyan `#75CEDF` | `loadPalette()` `.map()` |
| **Classes, types and enums** | Lime `#B6FF9A` | `Palette` `string` `List<T>` |
| **Properties** | Blue `#79AFFF` | `swatch.name` |
| **Built-ins** | Rose `#E96BBE` | `this` `self` `JSON` |
| **Decorators** | Pink `#FF59CB` | `@sealed` `@dataclass` |
| **Comments** | Muted mauve `#897895`, italic | `// note` |

The full colour guide, including HTML, CSS, JSON, Markdown and every part of the editor, is on [GitHub](https://github.com/iri-dev/iri-theme#what-colour-is-what).

## Little Extras

Alongside the colours, iri theme comes with a few finishing touches:

- **A thin white line cursor** in both the editor and the terminal.
- **Pill-shaped tabs** in VS Code's Modern UI (where your version has it).
- **A slimmer horizontal scrollbar** that stays out of your way.

Your own settings always take priority, so you can change any of these whenever you like.

## Turn It On

After installing, press `Ctrl+K` `Ctrl+T` (`Cmd+K` `Cmd+T` on macOS) and pick **iri theme**.
